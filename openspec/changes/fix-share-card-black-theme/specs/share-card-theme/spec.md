## Purpose

让分享卡片始终使用深色配色，允许用户主动选择背景；预览和导出结果可预期，不会因为用量总量、时间范围、指标或服务筛选而自动改变背景。

## ADDED Requirements

### Requirement: 分享卡片使用可选的深色背景
系统 SHALL 提供纯色、极光、轨道和网格四种深色背景，文字、分隔线、曲线和提供商颜色 SHALL 使用同一套深色配色。背景样式 MUST NOT 随 API 换算价值、token 总量、时间范围、展示指标、卡片比例或所选服务自动变化。工作室中的预览 SHALL 与导出的 PNG 使用相同的背景样式。未曾选择背景时 SHALL 默认纯色。

#### Scenario: 用量总量跨过原有的等级门槛
- **WHEN** 所选范围的总量低于 $1K / 1 亿 token，或达到 $10K / 10 亿 token 及以上
- **THEN** 卡片仍使用当前选择的深色背景，不出现由用量自动触发的白色或蓝色背景

#### Scenario: 切换展示指标、时间范围或服务
- **WHEN** 用户在 API 换算价值与 Token 之间切换，或更改时间范围、卡片比例、勾选的服务
- **THEN** 卡片数值和图表随之更新，背景选择和深色配色保持不变

#### Scenario: 用户切换背景
- **WHEN** 用户选择纯色、极光、轨道或网格
- **THEN** 工作室立即显示对应背景，并在下次打开时保留该选择

#### Scenario: 导出与预览一致
- **WHEN** 用户保存 PNG、复制图片或通过分享菜单发送卡片
- **THEN** 导出图片的背景与工作室预览中的用户选择相同，且为深色

### Requirement: 分享产物不暗示用量等级
分享文案和导出文件名 MUST NOT 包含按用量划分的卡片颜色或等级称谓（如"白色卡片""黑色卡片""蓝色卡片"）。token 紧凑数字 SHALL 按常规四舍五入显示。金额里程碑标题及其"不因取整虚报里程碑"的规则保持不变。

#### Scenario: 复制或分享文案
- **WHEN** 用户以任一指标复制或分享卡片文案
- **THEN** 文案包含标题、数值、活跃天数、提供商和日期等信息，但不包含卡片颜色或等级名称

#### Scenario: 保存 PNG 的默认文件名
- **WHEN** 用户保存卡片 PNG
- **THEN** 默认文件名包含时间范围、日期、指标、比例和所选背景样式，不包含按用量划分的颜色或等级字段

#### Scenario: token 数接近进位
- **WHEN** token 总量为 99,960,000
- **THEN** 卡片显示为 100M，而不是为避开原有等级门槛显示为 99.9M

#### Scenario: 金额接近里程碑
- **WHEN** API 换算价值为 $999.996
- **THEN** 金额显示不得四舍五入成 $1,000.00 并获得"四位数"里程碑标题
