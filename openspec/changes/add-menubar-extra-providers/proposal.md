## Why

macOS 27 在刘海右侧加入了"显示隐藏菜单栏项目"的箭头按钮，这个位置正好被灵动岛右侧的提供方图标盖住。改用"显示位置 → 菜单栏"模式可以避开这个问题，但菜单栏图标原来最多只能显示两个提供方，同时关注更多模型的用户仍然看不全。另外，设置中"显示位置"一栏缺少中文翻译，中文系统下会显示英文。

## What Changes

- 提供方选择上限从 2 个提高到 4 个。前两个仍对应灵动岛和展开面板的左右位置，第 3、4 个只显示在菜单栏图标里。
- 设置 → 提供商新增"更多（菜单栏显示）"一栏，选了左右两个提供方后可以再添加或移除最多两个。
- 选择"只用一个提供方"时，额外添加的提供方会一并清除。
- 为"显示位置"一栏（标题、自动 / 刘海 / 菜单栏、说明文字）以及面板、成本页、概览页中遗漏的文案补充中文翻译。
- README 中英文两份已经过时（缺少 Grok、Antigravity，Claude 凭据说明错误，中文版缺少大量章节），全面更新并保持两份一致。

## Capabilities

### New Capabilities
- `menubar-extra-providers`: 菜单栏图标可以显示灵动岛两个位置之外的额外提供方。

### Modified Capabilities

## Impact

- 修改 `ProviderVisibilityStore`（上限、`extras`、`toggleExtra`）和 `ProviderSelectionView`（新增额外提供方选择）。
- 菜单栏图标 `MenuBarController` 本来就显示全部已选提供方，不需要改动。
- 用量抓取、超额提醒都按已选提供方计算，所以额外提供方也会被抓取和提醒；在刘海模式下它们不会出现在岛上。
- 补充中英文本地化文案，更新 README，新增选择逻辑的单元测试。
- 不涉及凭据、轮询间隔或 Sparkle 更新流程。
